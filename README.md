# Lahore Smart Transit Guide

A multi-modal transit routing web application built for Lahore, helping students and commuters find the best routes using the Orange Line, Metro Bus, Speedo buses, and EV transit networks, powered by Gemini AI.

## Live Application
* **Live Vercel URL:** https://lahore-smart-transit-guide.vercel.app 
* **GitHub Repository:** https://github.com/YOUR-USERNAME/lahore-smart-transit-guide 

## Features
* **AI-Powered Routing:** Uses Gemini AI (`gemini-3.5-flash`) to calculate intelligent transit paths across Lahore.
* **Fare & Time Estimates:** Provides estimated travel times and ticket prices in PKR.
* **Mobile-Friendly UI:** Designed for quick lookups on smartphones.

## Tech Stack
* **Frontend/Backend:** Next.js / React (built with Bolt.new)
* **AI API:** Google GenAI SDK (Gemini Flash)
* **Hosting:** Vercel
