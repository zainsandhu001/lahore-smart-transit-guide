# Lahore Smart Transit Guide

A smart transit routing web application built for Lahore. It helps students and daily commuters find the best travel routes using the Orange Line, Metro Bus, Speedo buses, and EV transit networks, powered by Gemini AI.

## Live Application
* **Live Vercel URL:** https://lahore-smart-transit-guide.vercel.app
* **GitHub Repository:** https://github.com/zainsandhu001/lahore-smart-transit-guide

## Features
* **AI-Powered Routing:** Uses Gemini AI to calculate smart travel paths across Lahore.
* **Fare & Time Estimates:** Shows estimated travel times and ticket prices in Pakistani Rupees (PKR).
* **Mobile-Friendly UI:** Designed to work easily on smartphones.

## Tech Stack
* **Frontend/Backend:** Next.js / React (built with Bolt.new)
* **AI API:** Google GenAI SDK (Gemini Flash)
* **Hosting:** Vercel
